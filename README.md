## 👥 Team & Collaboration

DebugArena is a collaborative group project developed as part of the **Nebius × NVIDIA Global AI Hackathon**, under the **Coding and Agentic Engineering** track.

Our team worked together to build an AI-powered coding agent evaluation and trajectory-generation platform. The project focuses on evaluating autonomous coding agents through real-world debugging tasks, isolated execution environments, benchmark testing, and structured training-data generation.
