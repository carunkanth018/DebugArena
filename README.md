## DebugArena — Nebius × NVIDIA Global AI Hackathon Project 👥🔥

**DebugArena** is a collaborative group hackathon project developed for the **Nebius × NVIDIA Global AI Hackathon**, under the **Coding and Agentic Engineering** track.

Our team collaborated to develop an AI-powered coding agent evaluation and trajectory-generation platform that evaluates autonomous coding agents through real-world debugging tasks, isolated execution environments, benchmark testing, and training-data generation.
